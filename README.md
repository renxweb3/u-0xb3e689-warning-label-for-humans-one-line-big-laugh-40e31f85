The safety warning label that should come printed on every human being:
runs on caffeine and spite, overheats under deadlines, and may
spontaneously start a sentence with "well, actually". Funny first,
plausible second.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
